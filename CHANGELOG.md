# Changelog

## 1.1.0

- Cobertura ampliada a más de 70 iconos y 228 extensiones: lenguajes de
  programación, web, datos, configuración, medios, fuentes, comprimidos, Docker,
  Git y documentos.
- Iconos de lenguaje generados desde una sola tabla (`scripts/build-icons.js`):
  página crema, sticker con color por familia y glifo o sigla.
- Siglas convertidas a paths para no depender de fuentes instaladas.
- Lámina del set completo en `assets/icons-preview.png`.
- Captura del tema en uso en `assets/preview.png`.

## 1.0.0

- Tema de iconos **Indie Icons** para el explorador: hoja, café, nota musical,
  documento, carpeta y carpeta abierta.
- Iconos dibujados en SVG (detallados, con degradados y sombras) y exportados a
  PNG de 128×128.
- Tema de color **Indie Dark** a juego.
